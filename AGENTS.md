# Skill visibility

When the main agent actually begins applying any skill, whether selected automatically or named by the user, first send a concise commentary message: `🧩 正在使用 skill：<skill-name> — <brief purpose>`. Use the skill's actual name and announce each newly selected skill before its first action. Do not repeat the message while continuing the same skill workflow. Merely mentioning, considering, or reading a skill for reference does not count as applying it. Do not report skills used only by subagents, send a completion notice, or create a persistent status display.
